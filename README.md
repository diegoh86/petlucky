# PetLucky - Landing Page Institucional

Landing Page moderna, de alta conversão e 100% responsiva para a **PetLucky** (Petshop, Banho e Tosa ozonizado, Consultas Veterinárias, Vacinas, Rações e Delivery).

## 🔗 Links

- **Repositório GitHub**: [https://github.com/diegoh86/petlucky](https://github.com/diegoh86/petlucky)
- **Site Online (GitHub Pages)**: [https://diegoh86.github.io/petlucky/](https://diegoh86.github.io/petlucky/)

## 🚀 Como Ativar o GitHub Pages

1. Acesse: [https://github.com/diegoh86/petlucky/settings/pages](https://github.com/diegoh86/petlucky/settings/pages)
2. Em **Build and deployment > Source**, escolha **Deploy from a branch**.
3. Selecione a branch `main` e a pasta `/ (root)`.
4. Clique em **Save**. Em cerca de 1 minuto o link `https://diegoh86.github.io/petlucky/` estará no ar!
