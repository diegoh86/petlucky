# PetLucky - Landing Page Institucional (Tijuca, RJ)

Landing Page moderna, de alta conversão e 100% responsiva para a **PetLucky** (Petshop, Banho e Tosa e Clínica Veterinária na Tijuca, Rio de Janeiro).

## 🚀 Tecnologias Utilizadas

- **HTML5 Semântico**: Marcação otimizada para acessibilidade e SEO.
- **Tailwind CSS**: Estilização moderna e responsiva com paleta customizada (Verde Sábio `#84BBA0`, Grafite `#1A2E26`, Verde WhatsApp `#25D366`).
- **FontAwesome & Google Fonts**: Ícones vetoriais de alta performance e tipografia `Plus Jakarta Sans`.
- **JSON-LD (Schema.org)**: Dados estruturados para indexação local no Google Search e Google Maps.
- **JavaScript (Vanilla)**: Interatividade leve para menu móbile, redirecionamento interativo de WhatsApp e scroll suave.

## 🌐 Publicação no GitHub Pages

Este projeto foi construído para ser servido como um site estático. Para publicar no GitHub Pages:

1. Crie um repositório no seu GitHub chamado `petlucky-website`.
2. Inicialize o repositório local e faça a publicação:
   ```bash
   git init
   git add .
   git commit -m "feat: Landing Page institucional PetLucky Tijuca"
   git branch -M main
   git remote add origin https://github.com/SEU_USUARIO/petlucky-website.git
   git push -u origin main
   ```
3. No GitHub, acesse **Settings > Pages** e selecione a branch `main` e a pasta `/ (root)`.
